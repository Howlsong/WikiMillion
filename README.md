# WikiMillion

An offline, searchable archive of Wikipedia.

WikiMillion is a personal project for building a local copy of a large selection of English Wikipedia articles. It downloads articles from Wikipedia, stores them locally as Markdown, indexes them with SQLite FTS5, and provides a lightweight local web interface for browsing and searching the archive.

The goal is simple: **Wikipedia, but available when the Internet isn't.**

## Features

* Downloads a curated collection of English Wikipedia articles
* Stores articles as plain Markdown files
* Resumable scraping
* SQLite-based full-text search using FTS5
* Local web interface
* Markdown rendering, including tables
* Dark mode
* Runs entirely on the local machine once the archive has been downloaded and indexed

## How It Works

The project has three main stages:

1. A URL manifest is generated from Wikimedia pageview data.
2. The scraper downloads the selected Wikipedia articles into `WikiMillion/`.
3. `build_index.py` creates a searchable SQLite database, which `server.py` exposes through a local web interface.

The resulting archive can be used without an Internet connection.

## Requirements

* Python 3
* SQLite with FTS5 support
* Internet access for the initial download
* Enough storage space for the archive

## Usage

First, populate the URL list and run the scraper.

Once the articles have been downloaded, build the search index:

```bash
python build_index.py
```

Then start the local server:

```bash
python server.py
```

Open the address printed by the server in a web browser.

## Project Status

WikiMillion is an ongoing personal project.

The current archive is generated from Wikimedia pageview statistics rather than attempting to mirror every article on Wikipedia. The exact contents therefore depend on the pageview data and the date on which the manifest was generated.

The project is functional, but the archive-building process is intentionally fairly simple and may change substantially as the project develops.

## Why "WikiMillion"?

It started as an attempt to make a local archive of roughly a million Wikipedia pages.

It turns out that collecting the most-viewed pages over a finite period and then deduplicating them produces considerably fewer unique articles than that.

The name survived anyway.
